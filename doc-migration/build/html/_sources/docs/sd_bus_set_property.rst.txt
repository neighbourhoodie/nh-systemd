Description
###########

These functions set or query D-Bus properties. D-Bus properties are service fields exposed via the :code:`org.freedesktop.DBus.Properties` interface. Under the hood, these functions call methods of the :code:`org.freedesktop.DBus.Properties` interface and as a result their semantics are similar to :ref:`sd_bus_call_method(3)`.

:code:`sd_bus_set_property()` sets a D-Bus property. If setting the property fails or an internal error occurs, an error is returned and an extended description of the error is optionally stored in :code:`ret_error` if it is not :code:`NULL`. :code:`type` and the arguments that follow it describe the new value of the property and must follow the format described in :ref:`sd_bus_message_append(3)`.

:code:`sd_bus_set_propertyv()` is equivalent to :code:`sd_bus_set_property()`, except that it is called with a "va_list" instead of a variable number of arguments.

:code:`sd_bus_get_property()` queries a D-Bus property. If retrieving the property fails or an internal error occurs, an error is returned and an extended description of the error is optionally stored in :code:`ret_error` if it is not :code:`NULL`. On success, the property is stored in :code:`reply`. :code:`type` describes the property type and must follow the format described in :ref:`sd_bus_message_append(3)`.

:code:`sd_bus_get_property_trivial()`, :code:`sd_bus_get_property_string()` and :code:`sd_bus_get_property_strv()` are shorthands for :code:`sd_bus_get_property()` that are used to query basic, string and string vector properties respectively. The caller is responsible for freeing the string and string vector results stored in :code:`ret` by :code:`sd_bus_get_property_string()` and :code:`sd_bus_get_property_strv()`.

Return Value
############

On success, these functions return a non-negative integer. On failure, they return a negative errno-style error code.
