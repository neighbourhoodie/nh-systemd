sd-bus(3)
=========

Name
####

sd-bus — A lightweight D-Bus IPC client library

Synopsis
########

:code:`#include <systemd/sd-bus.h>`

:code:`pkg-config --cflags --libs libsystemd`

Description
###########

:code:`sd-bus.h` is part of :man-pages:`libsystemd(3)` and provides an implementation of a D-Bus IPC client. See `<https://www.freedesktop.org/software/dbus/>`_ for more information about D-Bus IPC.
