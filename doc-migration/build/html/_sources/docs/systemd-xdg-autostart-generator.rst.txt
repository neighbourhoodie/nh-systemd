==================================
systemd-xdg-autostart-generator(8)
==================================

Name
####

systemd-xdg-autostart-generator — User unit generator for XDG autostart files

Synopsis
########

:code:`/usr/lib/systemd/user-generators/systemd-xdg-autostart-generator`

Description
###########

:code:`systemd-xdg-autostart-generator` is a generator that creates .service units for `XDG autostart <https://specifications.freedesktop.org/autostart-spec/autostart-spec-latest.html>`_ files. This permits desktop environments to delegate startup of these applications to :ref:`systemd(1)` .

Units created by :code:`systemd-xdg-autostart-generator` can be started by the desktop environment using "xdg-desktop-autostart.target". See :ref:`systemd.special(7)` for more details.

XDG autostart may be conditionalized using both standardized and non-standardized keys. In order to handle these, the generator may create one or more :code:`ExecCondition=` entries. For non-standardized keys, well-known helper binaries provided by Desktop Environments are used. All external helpers *must* detect their corresponding desktop environment and detect their corresponding desktop environment and *must* return success when run in a different environment. This is important as all return success when run in a different environment. This is important as all :code:`ExecCondition=` directives must succeed for an application to be started.

.. list-table:: Special XDG desktop file entries that are processed
   :header-rows: 1

   * - Entry
     - Handling
   * - :code:`Hidden=`, :code:`X-systemd-skip=`
     - No service will be generated if set to true
   * - :code:`OnlyShowIn=`, :code:`NotShowIn=`
     - :code:`ExecCondition=` using :code:`systemd-xdg-autostart-condition`
   * - :code:`TryExec=`
     - No service will be generated if the binary does not exist or cannot be executed
   * - :code:`AutostartCondition=` (GNOME extension)
     - :code:`ExecCondition=` using :code:`gnome-systemd-autostart-condition`
   * - :code:`X-GNOME-Autostart-Phase=`
     - No service will be generated if set to any value
   * - :code:`X-KDE-autostart-condition=`
     - :code:`ExecCondition=` using :code:`kde-systemd-start-condition`

:code:`systemd-xdg-autostart-generator` implements :ref:`systemd.generator(7)`.
