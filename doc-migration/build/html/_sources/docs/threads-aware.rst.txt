.. inclusion-marker-do-not-remove getenv|

.. inclusion-marker-do-not-remove getenv|

The code described here uses :man-pages:`getenv(3)`, which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call :man-pages:`setenv(3)` from a parallel thread. It is recommended to only do calls to :code:`setenv()` from an early phase of the program when no other threads have been started.
