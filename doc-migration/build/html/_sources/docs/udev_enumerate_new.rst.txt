=====================
udev_enumerate_new(3)
=====================

Name
####

udev_enumerate_new, udev_enumerate_ref, udev_enumerate_unref — Create, acquire and release a udev enumerate object

Synopsis
########

:code:`#include <libudev.h>` .. code-block::

   struct udev_enumerate *udev_enumerate_new(struct udev *udev); .. code-block::

   struct udev_enumerate *udev_enumerate_ref(struct udev_enumerate *udev_enumerate); .. code-block::

   struct udev_enumerate *udev_enumerate_unref(struct udev_enumerate *udev_enumerate);

Description
###########

:code:`udev_enumerate_new()` creates an enumeration context to scan :code:`/sys/`.

:code:`udev_enumerate_ref()` takes a reference of an enumeration context.

:code:`udev_enumerate_unref()` drops a reference of an enumeration context. If the refcount reaches zero, all resources of the enumeration context will be released.

Return Value
############

On success, :code:`udev_enumerate_new()` returns a pointer to the allocated enumeration object. On failure, :code:`NULL` is returned. :code:`udev_enumerate_ref()` returns the argument that it was passed, unmodified. :code:`udev_enumerate_unref()` always returns :code:`NULL`.

History
#######

:code:`udev_enumerate_new()`, :code:`udev_enumerate_ref()`, and :code:`udev_enumerate_unref()` were added in version 221.
