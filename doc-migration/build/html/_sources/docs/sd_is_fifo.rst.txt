Description
###########

:code:`sd_is_fifo()` may be called to check whether the specified file descriptor refers to a FIFO or pipe. If the :code:`path` parameter is not :code:`NULL`, it is checked whether the FIFO is bound to the specified file system path.

:code:`sd_is_socket()` may be called to check whether the specified file descriptor refers to a socket. If the :code:`family` parameter is not :code:`AF_UNSPEC`, it is checked whether the socket is of the specified family (:code:`AF_UNIX`, :code:`AF_INET`, …). If the :code:`type` parameter is not 0, it is checked whether the socket is of the specified type (:code:`SOCK_STREAM`, :code:`SOCK_DGRAM`, …). If the :code:`listening` parameter is positive, it is checked whether the socket is in accepting mode, i.e. :code:`listen()` has been called for it. If :code:`listening` is 0, it is checked whether the socket is not in this mode. If the parameter is negative, no such check is made. The :code:`listening` parameter should only be used for stream sockets and should be set to a negative value otherwise.

:code:`sd_is_socket_inet()` is similar to :code:`sd_is_socket()`, but optionally checks the IPv4 or IPv6 port number the socket is bound to, unless :code:`port` is zero. For this call :code:`family` must be passed as either :code:`AF_UNSPEC`, :code:`AF_INET`, or :code:`AF_INET6`.

:code:`sd_is_socket_sockaddr()` is similar to :code:`sd_is_socket_inet()`, but checks if the socket is bound to the address specified by :code:`addr`. The :code:`family` specified by :code:`addr` must be either :code:`AF_INET` or :code:`AF_INET6` and :code:`addr_len` must be large enough for that family. If :code:`addr` specifies a non-zero port, it is also checked if the socket is bound to this port. In addition, for IPv6, if :code:`addr` specifies non-zero :code:`sin6_flowinfo` or :code:`sin6_scope_id`, it is checked if the socket has the same values.

:code:`sd_is_socket_unix()` is similar to :code:`sd_is_socket()` but optionally checks the :code:`AF_UNIX` path the socket is bound to, unless the :code:`path` parameter is :code:`NULL`. For normal file system :code:`AF_UNIX` sockets, set the :code:`length` parameter to 0. For Linux abstract namespace sockets, set the :code:`length` to the size of the address, including the initial 0 byte, and set the :code:`path` to the initial 0 byte of the socket address.

:code:`sd_is_mq()` may be called to check whether the specified file descriptor refers to a POSIX message queue. If the :code:`path` parameter is not :code:`NULL`, it is checked whether the message queue is bound to the specified name.

:code:`sd_is_special()` may be called to check whether the specified file descriptor refers to a special file. If the :code:`path` parameter is not :code:`NULL`, it is checked whether the file descriptor is bound to the specified filename. Special files in this context are character device nodes and files in :code:`/proc/` or :code:`/sys/`.

Return Value
############

On failure, these calls return a negative errno-style error code. If the file descriptor is of the specified type and bound to the specified address, a positive return value is returned, otherwise zero.

Internally, these functions use a combination of :man-pages:`fstat(2)` and :man-pages:`getsockname(2)` to check the file descriptor type and where it is bound to.
