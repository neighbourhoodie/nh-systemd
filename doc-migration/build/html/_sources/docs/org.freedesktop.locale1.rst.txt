Name
####

org.freedesktop.locale1 — The D-Bus interface of systemd-localed

Introduction
############

:ref:`systemd-localed.service(8)` is a system service that can be used to control the system locale and keyboard mapping from user programs. This page describes the D-Bus interface.

The D-Bus API
#############

The service exposes the following interfaces on the bus:

.. code-block:: sh

   node /org/freedesktop/locale1 {
     interface org.freedesktop.locale1 {
       methods:
         SetLocale(in  as locale,
                   in  b interactive);
         SetVConsoleKeyboard(in  s keymap,
                             in  s keymap_toggle,
                             in  b convert,
                             in  b interactive);
         SetX11Keyboard(in  s layout,
                        in  s model,
                        in  s variant,
                        in  s options,
                        in  b convert,
                        in  b interactive);
       properties:
         readonly as Locale = ['...', ...];
         readonly s X11Layout = '...';
         readonly s X11Model = '...';
         readonly s X11Variant = '...';
         readonly s X11Options = '...';
         readonly s VConsoleKeymap = '...';
         readonly s VConsoleKeymapToggle = '...';
     };
     interface org.freedesktop.DBus.Peer { ... };
     interface org.freedesktop.DBus.Introspectable { ... };
     interface org.freedesktop.DBus.Properties { ... };
   };

Methods
#######

If you set a new system locale all old system locale settings will be dropped and the new settings will be saved to disk. The locale will also be passed to the system manager, and subsequently started daemons will inherit the new system locale. Note that already running daemons will not learn about the new value.

The :code:`SetVConsoleKeyboard()` method may be used to set the key mapping for the virtual console. Similarly, :code:`SetX11Keyboard()` may be used to set the default key mapping of any X11 servers.

Note that :code:`SetVConsoleKeyboard()` instantly applies the new key mapping to the console, while :code:`SetX11Keyboard()` simply sets a default that may be used by later sessions.

The boolean argument :code:`convert` may be set to optionally convert the console keyboard configuration to X11 keyboard mappings and vice versa. If true and :code:`SetVConsoleKeyboard()` is used, the nearest X11 keyboard setting for the chosen console setting is set. If true and :code:`SetX11Keyboard()` is used, the nearest console keyboard setting for the chosen X11 setting is set. Hence, it is usually sufficient to call only one of the two functions.

For graphical UIs that need to set the system keyboard mapping simply invoke :code:`SetX11Keyboard()`, set :code:`convert=true` and ignore :code:`SetVConsoleKeyboard()`.

Use the empty string for the keymap parameters you wish not to set.

The :code:`interactive` boolean parameters can be used to control whether `polkit <https://www.freedesktop.org/software/polkit/docs/latest/>`_ should interactively ask the user for authentication credentials if required.

Signals
#######

Whenever the system locale or keymap is changed via the daemon, :code:`PropertyChanged` signals are sent out to clients which have subscribed.

Properties
##########

The system locale is shown in the :code:`Locale` property. It is an array containing environment-variable-assignment-like strings. The following strings are known: :code:`LANG=`, :code:`LC_CTYPE=`, :code:`LC_NUMERIC=`, :code:`LC_TIME=`, :code:`LC_COLLATE=`, :code:`LC_MONETARY=`, :code:`LC_MESSAGES=`, :code:`LC_PAPER=`, :code:`LC_NAME=`, :code:`LC_ADDRESS=`, :code:`LC_TELEPHONE=`, :code:`LC_MEASUREMENT=`, :code:`LC_IDENTIFICATION=`.

The :code:`X11Layout`, :code:`X11Model`, :code:`X11Variant`, and :code:`X11Options` properties show values configurable with :code:`SetX11Keyboard()` described above (or :code:`SetVConsoleKeyboard()` with :code:`convert=true`). The :code:`VConsoleKeymap` and :code:`VConsoleKeymapToggle` properties show values configurable with :code:`SetVConsoleKeyboard()` (or :code:`SetX11Keyboard()` with :code:`convert=true`).

Security
########

Changing the system locale or keymap using this interface is authenticated via polkit. The polkit action for :code:`SetLocale()` is :code:`org.freedesktop.locale1.set-locale`. The polkit action for :code:`SetX11Keyboard()` and :code:`SetVConsoleKeyboard()` is :code:`org.freedesktop.locale1.set-keyboard`.

Examples
########

-----------------------------------------------------

.. code-block:: sh

   $ gdbus introspect --system \
     --dest org.freedesktop.locale1 \
     --object-path /org/freedesktop/locale1
