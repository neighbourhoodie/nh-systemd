oomd.conf(5)

####

oomd.conf, oomd.conf.d — Global

########

Description
###########

These files configure the various parameters of the :ref:`systemd(1)` userspace out-of-memory (OOM) killer, :ref:`systemd-oomd.service(8)`. See :ref:`systemd.syntax(7)` for a general description of the syntax.

[OOM] Section Options
#####################

The following options are available in the \[OOM] section:

.. systemd:option:: SwapUsedLimit=
   :group: config-directives

   Sets the limit for memory and swap usage on the system before :code:`systemd-oomd` will take action. If the fraction of memory used and the fraction of swap used on the system are both more than what is defined here, :code:`systemd-oomd` will act on eligible descendant control groups with swap usage greater than 5% of total swap, starting from the ones with the highest swap usage. Which control groups are monitored and what action gets taken depends on what the unit has configured for :systemd:var:`ManagedOOMSwap=`. Takes a value specified in percent (when suffixed with "%"), permille ("‰") or permyriad ("‱"), between 0% and 100%, inclusive. Defaults to 90%.

   .. versionadded:: 247

.. systemd:option:: DefaultMemoryPressureLimit=
   :group: config-directives

   Sets the limit for memory pressure on the unit's control group before :code:`systemd-oomd` will take action. A unit can override this value with :systemd:var:`ManagedOOMMemoryPressureLimit=`. The memory pressure for this property represents the fraction of time in a 10 second window in which all tasks in the control group were delayed. For each monitored control group, if the memory pressure on that control group exceeds the limit set for longer than the duration set by :systemd:var:`DefaultMemoryPressureDurationSec=`, :code:`systemd-oomd` will act on eligible descendant control groups, starting from the ones with the most reclaim activity to the least reclaim activity. Which control groups are monitored and what action gets taken depends on what the unit has configured for :systemd:var:`ManagedOOMMemoryPressure=`. Takes a fraction specified in the same way as :systemd:var:`SwapUsedLimit=` above. Defaults to 60%.

   .. versionadded:: 247

.. systemd:option:: DefaultMemoryPressureDurationSec=
   :group: config-directives

   Sets the amount of time a unit's control group needs to have exceeded memory pressure limits before :code:`systemd-oomd` will take action. A unit can override this value with :systemd:var:`ManagedOOMMemoryPressureDurationSec=`. Memory pressure limits are defined by :systemd:var:`DefaultMemoryPressureLimit=` and :systemd:var:`ManagedOOMMemoryPressureLimit=`. Must be set to 0, or at least 1 second. Defaults to 30 seconds when unset or 0.

   .. versionadded:: 248
