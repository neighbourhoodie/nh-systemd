==============================
sd_event_source_get_pending(3)
==============================

Name
####

sd_event_source_get_pending — Determine pending state of event sources

Synopsis
########

:code:`#include <systemd/sd-event.h>` .. code-block::

   int sd_event_source_get_pending(sd_event_source *source);

Description
###########

:code:`sd_event_source_get_pending()` may be used to determine whether the event source object specified as :code:`source` has seen events but has not been dispatched yet (and thus is marked "pending").

Event source objects initially are not marked pending, when they are created with calls such as :ref:`sd_event_add_io(3)`, :ref:`sd_event_add_time(3)`, with the exception of those created with :ref:`sd_event_add_defer(3)` which are immediately marked pending, and :ref:`sd_event_add_exit(3)` for which the "pending" concept is not defined. For details see the respective manual pages.

In each event loop iteration one event source of those marked pending is dispatched, in the order defined by the event source priority, as set with :ref:`sd_event_source_set_priority(3)`.

For I/O event sources, as created with :ref:`sd_event_add_io(3)`, the call :ref:`sd_event_source_get_io_revents(3)` may be used to query the type of event pending in more detail.

Return Value
############

On success, :code:`sd_event_source_get_pending()` returns an integer greater than zero when the event source is marked pending, and zero when the event source is not marked pending. On failure, it returns a negative errno-style error code.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   :code:`source` is not a valid pointer to an sd_event_source object.

.. systemd:option:: -EDOM

   :code:`source` refers to an event source object created with :ref:`sd_event_add_exit(3)`.

.. systemd:option:: -ENOMEM

   Not enough memory.

.. systemd:option:: -ESTALE

   The event loop is already terminated.

.. systemd:option:: -ECHILD

   The event loop has been created in a different process, library or module instance.
