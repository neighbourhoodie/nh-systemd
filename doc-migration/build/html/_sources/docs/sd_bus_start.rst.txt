===============
sd_bus_start(3)
===============

Name
####

sd_bus_start — Initiate a bus connection to the D-bus broker daemon

Synopsis
########

:code:`#include <systemd/sd-bus.h>` .. code-block::

   int sd_bus_start(sd_bus *bus);

Description
###########

:code:`sd_bus_start()` connects an existing bus connection object to the D-Bus broker daemon, usually :die-net:`dbus-daemon(1)` or :mankier:`dbus-broker(1)`. The mechanism to use for the connection must be configured before the call to :code:`sd_bus_start()`, using one of :ref:`sd_bus_set_address(3)`, :ref:`sd_bus_set_fd(3)`, or :ref:`sd_bus_set_exec(3)`. :code:`sd_bus_start()` will open the connection socket or spawn the executable as needed, and asynchronously start a :code:`org.freedesktop.DBus.Hello()` call. The answer to the Hello call will be processed later from :ref:`sd_bus_process(3)`. If opening of the connection or queuing of the asynchronous call fail, the connection will be closed with :ref:`sd_bus_close(3)`.

In most cases, it is better to use :ref:`sd_bus_default_user(3)`, :ref:`sd_bus_default_system(3)` or related calls instead of the more low-level :code:`sd_bus_new()` and :code:`sd_bus_start()`. The higher-level functions not only allocate a bus object but also start the connection to a well-known bus in a single function call.

Return Value
############

On success, this function returns a non-negative integer. On failure, it returns a negative errno-style error code.

.. inclusion-marker-do-not-remove errors|

Errors
######

.. systemd:option:: -EINVAL

   The input parameter :code:`bus` is :code:`NULL`.

   .. versionadded:: 246

.. systemd:option:: -ENOPKG

   Bus object :code:`bus` could not be resolved.

   .. versionadded:: 246

.. systemd:option:: -EPERM

   The input parameter :code:`bus` is in a wrong state (:code:`sd_bus_start()` may only be called once on a newly-created bus object).

   .. versionadded:: 246

.. systemd:option:: -ECHILD

   The bus object :code:`bus` was created in a different process.

   .. versionadded:: 246

In addition, other connection-related errors may be returned. See :ref:`sd_bus_send(3)`.
