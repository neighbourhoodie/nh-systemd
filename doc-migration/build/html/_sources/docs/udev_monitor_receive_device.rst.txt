udev_monitor_receive_device, udev_monitor_enable_receiving, udev_monitor_set_receive_buffer_size, udev_monitor_get_fd, udev_monitor_get_udev — Query and modify device monitor

Return Value
############

On success, :code:`udev_monitor_receive_device()` returns a pointer to a newly referenced device that was received via the monitor. The caller is responsible to drop this reference when done. On failure, :code:`NULL` is returned.

On success, :code:`udev_monitor_enable_receiving()` and :code:`udev_monitor_set_receive_buffer_size()` return an integer greater than, or equal to, :code:`0`. On failure, a negative error code is returned.

On success, :code:`udev_monitor_get_fd()` returns the file descriptor used by this monitor. On failure, a negative error code is returned.

:code:`udev_monitor_get_udev()` always returns a pointer to the udev context that this monitor is associated with.
