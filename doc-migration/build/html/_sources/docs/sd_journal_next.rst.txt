sd_journal_next(3)
==================

Name
####

sd_journal_next, sd_journal_previous, sd_journal_step_one, sd_journal_next_skip, sd_journal_previous_skip, SD_JOURNAL_FOREACH, SD_JOURNAL_FOREACH_BACKWARDS — Advance or set back the read pointer in the journal

Description
###########

:code:`sd_journal_next()` advances the read pointer into the journal by one entry. The only argument taken is a journal context object as allocated via :ref:`sd_journal_open(3)`. After successful invocation the entry may be read with functions such as :ref:`sd_journal_get_data(3)`.

Similarly, :code:`sd_journal_previous()` sets the read pointer back one entry.

:code:`sd_journal_step_one()` also moves the read pointer. If the current location is the head of the journal, e.g. when this is called following :code:`sd_journal_seek_head()`, then this is equivalent to :code:`sd_journal_next()`, and the argument :code:`advanced` will be ignored. Similarly, if the current location is the tail of the journal, e.g. when this is called following :code:`sd_journal_seek_tail()`, then this is equivalent to :code:`sd_journal_previous()`, and :code:`advanced` will be ignored. Otherwise, this is equivalent to :code:`sd_journal_next()` when :code:`advanced` is non-zero, and :code:`sd_journal_previous()` when :code:`advanced` is zero.

:code:`sd_journal_next_skip()` and :code:`sd_journal_previous_skip()` advance/set back the read pointer by multiple entries at once, as specified in the :code:`skip` parameter. The :code:`skip` parameter must be less than or equal to 2147483647 (2³¹-1).

The journal is strictly ordered by reception time, and hence advancing to the next entry guarantees that the entry then pointing to is later in time than then previous one, or has the same timestamp.

Note that :ref:`sd_journal_get_data(3)` and related calls will fail unless :code:`sd_journal_next()` has been invoked at least once in order to position the read pointer on a journal entry.

Note that the :code:`SD_JOURNAL_FOREACH()` macro may be used as a wrapper around :ref:`sd_journal_seek_head(3)` and :code:`sd_journal_next()` in order to make iterating through the journal easier. See below for an example. Similarly, :code:`SD_JOURNAL_FOREACH_BACKWARDS()` may be used for iterating the journal in reverse order.

Return Value
############

The four calls return the number of entries advanced/set back on success or a negative errno-style error code. When the end or beginning of the journal is reached, a number smaller than requested is returned. More specifically, if :code:`sd_journal_next()` or :code:`sd_journal_previous()` reach the end/beginning of the journal they will return 0, instead of 1 when they are successful. This should be considered an EOF marker.
