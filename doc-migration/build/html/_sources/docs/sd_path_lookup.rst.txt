Description
###########

:code:`sd_path_lookup()` and :code:`sd_bus_path_lookup_strv()` return a single path or set of file system paths specified by the argument :code:`type`. In case of :code:`sd_path_lookup()` a single :code:`NUL`-terminated string is returned. When :code:`type` specifies a set of paths, they are concatenated using ":" as a separator (as is traditionally done for e.g. :code:`$PATH` or :code:`$LD_LIBRARY_PATH`). In case of :code:`sd_path_lookup_strv()` a :code:`NULL`-terminated array of strings is returned (strv). If suffix :code:`suffix` is given, it is concatenated to each of the paths after a slash ("/"). All returned paths are absolute.

For paths which refer to user directories, the relevant XDG standard is followed, with support for environment variables like :code:`$XDG_DOCUMENTS_DIR`, :code:`$XDG_DESKTOP_DIR`, ..., and explicit configuration in :code:`/etc/xdg/user-dirs.conf` or :code:`${XDG_CONFIG_HOME}/user-dirs.dirs`. See `XDG Base Directory Specification <https://specifications.freedesktop.org/basedir-spec/basedir-spec-latest.html>`_ for details.

:ref:`systemd-path(1)` is a wrapper around :code:`sd_path_lookup()` and allows the same set of paths to be queried.

Return Value
############

On success, :code:`sd_path_lookup()` and :code:`sd_path_lookup_strv()` return a non-negative integer. On failure, a negative errno-style error number is returned by either function.

The returned string or string array (strv) must be :man-pages:`free(3)`'d by the caller.

.. inclusion-marker-do-not-remove errors|

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EOPNOTSUPP

   Unknown identifier :code:`type`.

   .. versionadded:: 246

.. systemd:option:: -EINVAL

   Output argument is :code:`NULL`.

   .. versionadded:: 246

.. systemd:option:: -ENXIO

   Query failed because of an undefined environment variable (e.g. for :code:`SD_PATH_USER_RUNTIME` when :code:`$XDG_RUNTIME_DIR` is not defined).

   .. versionadded:: 246

.. systemd:option:: -ENOMEM

   Memory allocation failed.

   .. versionadded:: 246
