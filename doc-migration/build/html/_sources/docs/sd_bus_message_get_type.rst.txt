Description
###########

:code:`sd_bus_message_get_type()` returns the type of a message in the output parameter :code:`type`, one of :code:`SD_BUS_MESSAGE_METHOD_CALL`, :code:`SD_BUS_MESSAGE_METHOD_RETURN`, :code:`SD_BUS_MESSAGE_METHOD_ERROR`, :code:`SD_BUS_MESSAGE_SIGNAL`. This type is either specified as a parameter when the message is created using :ref:`sd_bus_message_new(3)`, or is set automatically when the message is created using :ref:`sd_bus_message_new_signal(3)`, :ref:`sd_bus_message_new_method_call(3)`, :ref:`sd_bus_message_new_method_error(3)` and similar functions.

:code:`sd_bus_message_get_error()` returns the error stored in the message :code:`m`, if there is any. Otherwise, it returns :code:`NULL`. :code:`sd_bus_message_get_errno()` returns the error stored in the message :code:`m` as a positive errno-style value, if there is any. Otherwise, it returns zero. Errors are mapped to errno values according to the default and any additional registered error mappings. See :ref:`sd-bus-errors(3)` and :ref:`sd_bus_error_add_map(3)`.

:code:`sd_bus_message_get_creds()` returns the message credentials attached to the message :code:`m`. If no credentials are attached to the message, it returns :code:`NULL`. Ownership of the credentials instance is not transferred to the caller and hence should not be freed.

:code:`sd_bus_message_is_signal()` checks if message :code:`m` is a signal message. If :code:`interface` is non-null, it also checks if the message has the same interface set. If :code:`member` is non-null, it also checks if the message has the same member set. Also see :ref:`sd_bus_message_new_signal(3)`. It returns true when all checks pass.

:code:`sd_bus_message_is_method_call()` checks if message :code:`m` is a method call message. If :code:`interface` is non-null, it also checks if the message has the same interface set. If :code:`member` is non-null, it also checks if the message has the same member set. Also see :ref:`sd_bus_message_new_method_call(3)`. It returns true when all checks pass.

:code:`sd_bus_message_is_method_error()` checks if message :code:`m` is an error reply message. If :code:`name` is non-null, it also checks if the message has the same error identifier set. Also see :ref:`sd_bus_message_new_method_error(3)`. It returns true when all checks pass.

Return Value
############

On success, these functions (except :code:`sd_bus_message_get_error()` and :code:`sd_bus_message_get_creds()`) return a non-negative integer. On failure, they return a negative errno-style error code. :code:`sd_bus_message_get_errno()` always returns a non-negative integer, even on failure.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   The message parameter :code:`m` or an output parameter is :code:`NULL`.
