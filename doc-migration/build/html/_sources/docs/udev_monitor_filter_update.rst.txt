Return Value

On success, :code:`udev_monitor_filter_update()`, :code:`udev_monitor_filter_remove()`, :code:`udev_monitor_filter_add_match_subsystem_devtype()` and :code:`udev_monitor_filter_add_match_tag()` return an integer greater than, or equal to, :code:`0`. On failure, a negative error code is returned.
