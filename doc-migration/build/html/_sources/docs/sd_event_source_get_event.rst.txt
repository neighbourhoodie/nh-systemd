============================
sd_event_source_get_event(3)
============================

Name
####

sd_event_source_get_event — Retrieve the event loop of an event source

Synopsis
########

:code:`#include <systemd/sd-event.h>` .. code-block::

   sd_event* sd_event_source_get_event(sd_event_source *source);

Description
###########

:code:`sd_event_source_get_event()` may be used to retrieve the event loop object the event source object specified as :code:`source` is associated with. The event loop object is specified when creating an event source object with calls such as :ref:`sd_event_add_io(3)` or :ref:`sd_event_add_time(3)`.

Return Value
############

On success, :code:`sd_event_source_get_event()` returns the associated event loop object. On failure, it returns :code:`NULL`.
