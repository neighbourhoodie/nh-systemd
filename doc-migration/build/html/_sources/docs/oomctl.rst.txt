oomctl(1)
=========

Name
####

oomctl — Analyze the state stored in

Synopsis
########

:code:`oomctl [OPTIONS...] {COMMAND}`

Description
###########

:code:`oomctl` may be used to get information about the various contexts read in by the :ref:`systemd(1)` userspace out-of-memory (OOM) killer, :ref:`systemd-oomd(8)`.

Commands
########

The following commands are understood:

.. systemd:option:: dump

   Show the current state of the cgroups and system contexts stored by :code:`systemd-oomd`.

   .. versionadded:: 247
