=================================
systemd-vconsole-setup.service(8)
=================================

Name
####

systemd-vconsole-setup.service, systemd-vconsole-setup — Configure the virtual consoles

Synopsis
########

:code:`systemd-vconsole-setup.service`

:code:`/usr/lib/systemd/systemd-vconsole-setup [TTY]`

Description
###########

:code:`systemd-vconsole-setup` sets up and configures either all virtual consoles, or — if the optional :emphasis:`TTY` parameter is provided — a specific one. When the system is booting up, :code:`systemd-vconsole-setup.service` is called by :ref:`systemd-udevd(8)` during VT console subsystem initialization. Also, :ref:`systemd-localed.service(8)` invokes it as needed when language or console changes are made. Internally, this program calls :mankier:`loadkeys(1)` and :die-net:`setfont(8)`.

Execute :code:`systemctl restart systemd-vconsole-setup.service` in order to apply any manual changes made to :code:`/etc/vconsole.conf`.

See :man-pages:`vconsole.conf(5)` for information about the configuration files and kernel command line options understood by this program.

Credentials
###########

:code:`systemd-vconsole-setup` supports the service credentials logic as implemented by :code:`ImportCredential=`/:code:`LoadCredential=`/:code:`SetCredential=` (see :ref:`systemd.exec(5)` for details). The following credentials are used when passed in:

.. systemd:option:: vconsole.keymap, vconsole.keymap_toggle
   :group: system-credentials

   The keymap (and toggle keymap) to apply. The matching options in :code:`vconsole.conf` and on the kernel command line take precedence over these credentials.

   Note the relationship to the :systemd:var:`firstboot.keymap` credential understood by :ref:`systemd-firstboot.service(8)`: both ultimately affect the same setting, but :systemd:var:`firstboot.keymap` is written into :code:`/etc/vconsole.conf` on first boot (if not already configured), and then read from there by :code:`systemd-vconsole-setup`, while :systemd:var:`vconsole.keymap` is read on every boot, and is not persisted to disk (but any configuration in :code:`vconsole.conf` will take precedence if present).

   .. versionadded:: 253

.. systemd:option:: vconsole.font, vconsole.font_map, vconsole.font_unimap
   :group: system-credentials

   The console font settings to apply. The matching options in :code:`vconsole.conf` and on the kernel command line take precedence over these credentials.

   .. versionadded:: 253
