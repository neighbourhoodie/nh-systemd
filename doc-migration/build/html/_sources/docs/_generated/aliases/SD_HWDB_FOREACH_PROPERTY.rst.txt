sd_hwdb_get(3)
==============

Name
####

sd_hwdb_get, sd_hwdb_seek, sd_hwdb_enumerate, SD_HWDB_FOREACH_PROPERTY — Seek to a location in hwdb or access entries

Description
###########

:code:`sd_hwdb_get()` queries the :code:`hwdb` object created earlier with :man-pages:`sd_hwdb_new(3)` for entries matching the specified string :code:`modalias`, and returns the value corresponding to the key :code:`key`. The value is returned as a :code:`NUL`-terminated string in :code:`value`. It must not be modified by the caller and is valid as long as a reference to :code:`hwdb` is kept. When multiple patterns in the database match :code:`modalias`, the one with the highest priority is used. See :man-pages:`hwdb(7)` for details.

:code:`sd_hwdb_seek()` selects entries matching the specified string :code:`modalias`. Subsequent queries with :code:`sd_hwdb_enumerate()` will access the key-value pairs for that string.

:code:`sd_hwdb_enumerate()` returns (in turn) all the key-value pairs defined for the string used with :code:`sd_hwdb_seek()`. Each pair is returned as :code:`NUL`-terminated strings in :code:`key` and :code:`value`. The strings must not be modified by the caller and are valid as long as a reference to :code:`hwdb` is kept. When multiple patterns in the database match :code:`modalias`, the combination of all matching key-value pairs is used. See :man-pages:`hwdb(7)` for details.

The :code:`SD_HWDB_FOREACH_PROPERTY()` macro combines :code:`sd_hwdb_seek()` and :code:`sd_hwdb_enumerate()`. No error handling is performed and iteration simply stops on error. See the example below.

Return Value
############

On success, :code:`sd_hwdb_get()` and :code:`sd_hwdb_seek()` return a non-negative integer. On failure, they return a negative errno-style error code.

:code:`sd_hwdb_enumerate()` returns a positive integer if another key-value pair was found or zero if all entries have already been enumerated. On failure, it returns a negative errno-style error code.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   A parameter is :code:`NULL`.

   .. versionadded:: 246

.. systemd:option:: -ENOENT

   An entry for the specified :code:`modalias` was not found.

   .. versionadded:: 246

.. systemd:option:: -EAGAIN

   :code:`sd_hwdb_seek()` was not called before :code:`sd_hwdb_enumerate()`.

   .. versionadded:: 246
