Description
###########

:code:`sd_bus_call_method()` is a convenience function for initializing a bus message object and calling the corresponding D-Bus method. It combines the :ref:`sd_bus_message_new_method_call(3)`, :ref:`sd_bus_message_append(3)` and :ref:`sd_bus_call(3)` functions into a single function call.

:code:`sd_bus_call_method_async()` is a convenience function for initializing a bus message object and calling the corresponding D-Bus method asynchronously. It combines the :ref:`sd_bus_message_new_method_call(3)`, :ref:`sd_bus_message_append(3)` and :ref:`sd_bus_call_async(3)` functions into a single function call.

Return Value
############

On success, these functions return a non-negative integer. On failure, they return a negative errno-style error code.
