systemd-quotacheck@.service(8)
==============================

Name
####

systemd-quotacheck@.service, systemd-quotacheck-root.service, systemd-quotacheck — File system quota checker logic

Synopsis
########

:code:`systemd-quotacheck@.service`

:code:`systemd-quotacheck-root.service`

:code:`/usr/lib/systemd/systemd-quotacheck`

Description
###########

:code:`systemd-quotacheck@.service` and :code:`systemd-quotacheck-root.service` are services responsible for file system quota checks. They run once at boot after all necessary file systems are mounted. They are pulled in only if at least one file system has quotas enabled.

Kernel Command Line
###################

:code:`systemd-quotacheck` understands one kernel command line parameter:

.. systemd:option:: quotacheck.mode=
   :group: kernel-commandline-options

   One of "auto", "force", "skip". Controls the mode of operation. The default is "auto", and ensures that file system quota checks are done when the file system quota checker deems them necessary. "force" unconditionally results in full file system quota checks. "skip" skips any file system quota checks.

   .. versionadded:: 186

Credentials
###########

:code:`systemd-quotacheck` supports the service credentials logic as implemented by :code:`ImportCredential=`/:code:`LoadCredential=`/:code:`SetCredential=` (see :ref:`systemd.exec(5)` for details). The following credentials are used when passed in:

.. systemd:option:: quotacheck.mode
   :group: system-credentials

   The contents of the credential is parsed as same as the kernel command line option with the same name. See above for more details.

   .. versionadded:: 258

Note that by default the :code:`systemd-quotacheck@.service` and :code:`systemd-quotacheck-root.service` unit files are set up to inherit :code:`quotacheck.mode` credential from the service manager.
