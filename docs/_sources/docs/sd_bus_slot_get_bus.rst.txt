Description
###########

:code:`sd_bus_slot_get_bus()` returns the bus object that message :code:`slot` is attached to.

:code:`sd_bus_slot_get_current_handler()`, :code:`sd_bus_slot_get_current_message()` and :code:`sd_bus_slot_get_current_userdata()` return the current handler, message and userdata respectively of the bus :code:`slot` is attached to if we're currently executing the callback associated with :code:`slot`.

Return Value
############

:code:`sd_bus_slot_get_bus()` always returns the bus object.

On success, :code:`sd_bus_slot_get_current_handler()`, :code:`sd_bus_slot_get_current_message()` and :code:`sd_bus_slot_get_current_userdata()` return the requested object. On failure, they return :code:`NULL`.
