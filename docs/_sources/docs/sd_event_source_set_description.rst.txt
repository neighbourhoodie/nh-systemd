==================================
sd_event_source_set_description(3)
==================================

Name
####

sd_event_source_set_description, sd_event_source_get_description — Set or retrieve descriptive names of event sources

Synopsis
########

:code:`#include <systemd/sd-event.h>` .. code-block::

   int sd_event_source_set_description(sd_event_source *source,
	const char *description); .. code-block::

   int sd_event_source_get_description(sd_event_source *source,
	const char **ret);

Description
###########

:code:`sd_event_source_set_description()` may be used to set an arbitrary descriptive name for the event source object specified as :code:`source`. This name will be used in debugging messages generated by :ref:`sd-event(3)` for this event source, and may be queried using :code:`sd_event_source_get_description()` for debugging purposes. The :code:`description` parameter shall point to a :code:`NUL`-terminated string or be :code:`NULL`. In the latter case, the descriptive name will be unset. The string is copied internally, hence the :code:`description` argument is not referenced after the function returns.

:code:`sd_event_source_get_description()` may be used to query the current descriptive name assigned to the event source object :code:`source`. It returns a pointer to the current name in :code:`ret`, stored in memory internal to the event source. The memory is invalidated when the event source is destroyed or the descriptive name is changed.

Event source objects generally have no description set when they are created, except for UNIX signal event sources created with :ref:`sd_event_add_signal(3)`, whose descriptive name is initialized to the signal's C constant name (e.g. "SIGINT" or "SIGTERM").

Return Value
############

On success, :code:`sd_event_source_set_description()` and :code:`sd_event_source_get_description()` return a non-negative integer. On failure, they return a negative errno-style error code.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   :code:`source` is not a valid pointer to an sd_event_source object or the :code:`description` argument for :code:`sd_event_source_get_description()` is :code:`NULL`.

.. systemd:option:: -ENOMEM

   Not enough memory to copy the name.

.. systemd:option:: -ECHILD

   The event loop has been created in a different process, library or module instance.

.. systemd:option:: -ENXIO

   No name was set for the event source.
