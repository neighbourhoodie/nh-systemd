============================
sd_bus_message_new_signal(3)
============================

Name
####

sd_bus_message_new_signal, sd_bus_message_new_signal_to — Create a signal message

Synopsis
########

:code:`#include <systemd/sd-bus.h>` .. code-block::

   int sd_bus_message_new_signal(sd_bus *bus,
	sd_bus_message **m,
	const char *path,
	const char *interface,
	const char *member); .. code-block::

   int sd_bus_message_new_signal_to(sd_bus *bus,
	sd_bus_message **m,
	const char *destination,
	const char *path,
	const char *interface,
	const char *member);

Description
###########

The :code:`sd_bus_message_new_signal()` function creates a new bus message object that encapsulates a D-Bus signal, and returns it in the :code:`m` output parameter. The signal will be sent to path :code:`path`, on the interface :code:`interface`, member :code:`member`. When this message is sent, no reply is expected. See :ref:`sd_bus_message_new_method_call(3)` for a short description of the meaning of the :code:`path`, :code:`interface`, and :code:`member` parameters.

:code:`sd_bus_message_new_signal_to()` is a shorthand for creating a new bus message to a specific destination. It's behavior is similar to calling :code:`sd_bus_message_new_signal()` followed by calling :ref:`sd_bus_message_set_destination(3)`.

Return Value
############

This function returns 0 if the message object was successfully created, and a negative errno-style error code otherwise.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   The output parameter :code:`m` is :code:`NULL`.

   The :code:`path` parameter is not a valid D-Bus path ("/an/object/path"), the :code:`interface` parameter is not a valid D-Bus interface name ("an.interface.name"), or the :code:`member` parameter is not a valid D-Bus member ("Name").

.. systemd:option:: -ENOTCONN

   The bus parameter :code:`bus` is :code:`NULL` or the bus is not connected.

.. systemd:option:: -ENOMEM

   Memory allocation failed.
