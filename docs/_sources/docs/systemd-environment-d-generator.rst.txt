Name
####

systemd-environment-d-generator, 30-systemd-environment-d-generator — Load variables specified by

Synopsis
########

:code:`|USER_ENV_GENERATOR_DIR|/30-systemd-environment-d-generator`

Description
###########

:code:`systemd-environment-d-generator` is a :ref:`systemd.environment-generator(7)` that reads environment configuration specified by :man-pages:`environment.d(5)` configuration files and passes it to the :ref:`systemd(1)` user manager instance.
