systemd-integritysetup-generator(8)
===================================

Name
####

systemd-integritysetup-generator — Unit generator for integrity protected block devices

Synopsis
########

:code:`/usr/lib/systemd/system-generators/systemd-integritysetup-generator`

Description
###########

:code:`systemd-integritysetup-generator` is a generator that translates :code:`/etc/integritytab` entries into native systemd units early at boot. This will create :ref:`systemd-integritysetup@.service(8)` units as necessary.

:code:`systemd-integritysetup-generator` implements :ref:`systemd.generator(7)`.

########
