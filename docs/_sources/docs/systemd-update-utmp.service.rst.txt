systemd-update-utmp.service(8)
==============================

Name
####

systemd-update-utmp.service, systemd-update-utmp — Write audit and utmp updates at bootup and shutdown

Synopsis
########

:code:`systemd-update-utmp.service`

:code:`/usr/lib/systemd/systemd-update-utmp`

Description
###########

:code:`systemd-update-utmp.service` is a service that writes system reboots and shutdown requests to utmp and wtmp, as well as the audit logs.

See Also
########

:ref:`systemd(1)`, :man-pages:`utmp(5)`, :man-pages:`auditd(8)`
