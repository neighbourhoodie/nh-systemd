systemd-tty-ask-password-agent(1)
=================================

Name
####

systemd-tty-ask-password-agent — List or process pending systemd password requests

Synopsis
########

:code:`systemd-tty-ask-password-agent [OPTIONS...] [VARIABLE=VALUE...]`

Description
###########

:code:`systemd-tty-ask-password-agent` is a password agent that handles password requests of the system, for example for hard disk encryption passwords or SSL certificate passwords that need to be queried at boot-time or during runtime.

:code:`systemd-tty-ask-password-agent` implements the `Password Agents Specification <https://systemd.io/PASSWORD_AGENTS/>`_, and is one of many possible response agents which answer to queries formulated with :ref:`systemd-ask-password(1)`.

Options
#######

The following options are understood:

.. systemd:option:: --list

   Lists all currently pending system password requests.

   .. versionadded:: 186

.. systemd:option:: --query

   Process all currently pending system password requests by querying the user on the calling TTY.

   .. versionadded:: 186

.. systemd:option:: --watch

   Continuously process password requests.

   .. versionadded:: 186

.. systemd:option:: --wall

   Forward password requests to :man-pages:`wall(1)` instead of querying the user on the calling TTY.

   .. versionadded:: 186

.. systemd:option:: --plymouth

   Ask question with :die-net:`plymouth(8)` instead of querying the user on the calling TTY.

   .. versionadded:: 186

.. systemd:option:: --console[=DEVICE]

   Ask question on TTY :emphasis:`DEVICE` instead of querying the user on the calling TTY. If :emphasis:`DEVICE` is not specified, :code:`/dev/console` will be used.

   .. versionadded:: 186

###########

On success, 0 is returned, a non-zero failure code otherwise.
