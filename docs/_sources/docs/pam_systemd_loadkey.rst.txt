======================
pam_systemd_loadkey(8)
======================

Name
####

pam_systemd_loadkey — Read password from kernel keyring and set it as PAM authtok

Synopsis
########

:code:`pam_systemd_loadkey.so`

Description
###########

:code:`pam_systemd_loadkey` reads a NUL-separated password list from the kernel keyring, and sets the last password in the list as the PAM authtok, which can be used by e.g. :man-pages:`pam_get_authtok(3)`.

The password list is supposed to be stored in the "user" keyring of the root user, by an earlier call to :ref:`systemd-ask-password(1)` with :code:`--keyname=`. You can pass the keyname to :code:`pam_systemd_loadkey` via the :code:`keyname=` option.

Options
#######

The following options are understood:

.. systemd:option:: keyname=
   :group: pam-directives

   Takes a string argument which sets the keyname to read. The default is "cryptsetup". During boot, :ref:`systemd-cryptsetup@.service(8)` stores a passphrase or PIN in the keyring. The LUKS2 volume key can also be used, via the :systemd:option:`link-volume-key` option in :man-pages:`crypttab(5)`.

   .. list-table:: Possible values for :systemd:var:`keyname`.
      :header-rows: 1

      * - Value
        - Description
      * - cryptsetup
        - Passphrase or recovery key
      * - fido2-pin
        - Security token PIN
      * - luks2-pin
        - LUKS2 token PIN
      * - tpm2-pin
        - TPM2 PIN

   .. versionadded:: 255

.. systemd:option:: debug
   :group: pam-directives

   The module will log debugging information as it operates.

   .. versionadded:: 255

Example
#######

This module is intended to be used when you use LUKS with a passphrase, enable autologin in the display manager, and want to unlock Gnome Keyring / KDE KWallet automatically. So in total, you only enter one password during boot.

You need to set the password of your Gnome Keyring/KWallet to the same as your LUKS passphrase. Then add the following lines to your display manager's PAM config under :code:`/etc/pam.d/` (e.g. :code:`sddm-autologin`):

.. code-block:: sh

   -auth       optional    pam_systemd_loadkey.so
   -auth       optional    pam_gnome_keyring.so
   -session    optional    pam_gnome_keyring.so auto_start
   -session    optional    pam_kwallet5.so auto_start

And add the following lines to your display manager's systemd service file, so it can access root's keyring:

.. code-block:: sh

   [Service]
   KeyringMode=inherit

In this setup, early during the boot process, :ref:`systemd-cryptsetup@.service(8)` will ask for the passphrase and store it in the kernel keyring with the keyname "cryptsetup". Then when the display manager does the autologin, :code:`pam_systemd_loadkey` will read the passphrase from the kernel keyring, set it as the PAM authtok, and then :code:`pam_gnome_keyring` and :code:`pam_kwallet5` will unlock with the same passphrase.
