Return Value
############

On success, :code:`udev_list_entry_get_next()` and :code:`udev_list_entry_get_by_name()` return a pointer to the requested list entry. If no such entry can be found, or on failure, :code:`NULL` is returned.

On success, :code:`udev_list_entry_get_name()` and :code:`udev_list_entry_get_value()` return a pointer to a constant string representing the requested value. The string is bound to the lifetime of the list entry itself. On failure, :code:`NULL` is returned.
