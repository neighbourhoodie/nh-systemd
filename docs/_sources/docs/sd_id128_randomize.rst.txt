=====================
sd_id128_randomize(3)
=====================

Name
####

sd_id128_randomize — Generate 128-bit IDs

Synopsis
########

:code:`#include <systemd/sd-id128.h>` .. code-block::

   int sd_id128_randomize(sd_id128_t *ret);

Description
###########

:code:`sd_id128_randomize()` generates a new randomized 128-bit ID and returns it in :code:`ret`. Every invocation returns a new randomly generated ID. This uses the :man-pages:`getrandom(2)` kernel random number generator.

Note that :code:`sd_id128_randomize()` always returns a UUID Variant 1 Version 4 compatible ID. It is hence guaranteed that this function will never return the ID consisting of all zero or all one bits (:code:`SD_ID128_NULL`, :code:`SD_ID128_ALLF`).

For more information about the "sd_id128_t" type, see :ref:`sd-id128(3)`.

:ref:`systemd-id128(1)`'s :code:`new` command may be used as a command line front-end for :code:`sd_id128_randomize()`.

Return Value
############

The call returns 0 on success (in which case :code:`ret` is filled in), or a negative errno-style error code.
