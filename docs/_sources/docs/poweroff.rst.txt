===========
poweroff(8)
===========

Name
####

poweroff, reboot, halt — Power off, reboot, or halt the machine

Synopsis
########

:code:`poweroff [OPTIONS...]`

:code:`reboot [OPTIONS...]`

:code:`halt [OPTIONS...]`

Description
###########

:code:`poweroff`, :code:`reboot`, and :code:`halt` may be used to power off, reboot, or halt the machine. All three commands take the same options.

Options
#######

The following options are understood:

.. systemd:option:: --help

   .. include:: standard-options.rst
       :start-after: .. inclusion-marker-do-not-remove help-para|
       :end-before: .. inclusion-end-marker-do-not-remove help-para|

   .. versionadded:: 253

.. systemd:option:: --halt

   Halt the machine, regardless of which one of the three commands is invoked.

   .. versionadded:: 253

.. systemd:option:: -p, --poweroff

   Power off the machine, when either :code:`halt` or :code:`poweroff` is invoked. This option is ignored when :code:`reboot` is invoked.

   .. versionadded:: 253

.. systemd:option:: --reboot

   Reboot the machine, regardless of which one of the three commands is invoked.

   .. versionadded:: 253

.. systemd:option:: -f, --force

   Force immediate power-off, halt, or reboot. If specified, the command does not contact the init system. In most cases, filesystems are not properly unmounted before shutdown. For example, the command :code:`reboot -f` is mostly equivalent to :code:`systemctl reboot -ff`, instead of :code:`systemctl reboot -f`.

   .. versionadded:: 253

.. systemd:option:: -w, --wtmp-only

   Only write wtmp shutdown entry, do not actually power off, reboot, or halt.

   .. versionadded:: 253

.. systemd:option:: -d, --no-wtmp

   Do not write wtmp shutdown entry.

   .. versionadded:: 253

.. systemd:option:: -n, --no-sync

   Do not sync hard disks/storage media before power-off, reboot, or halt.

   .. versionadded:: 253

.. systemd:option:: --no-wall

   Do not send wall message before power-off, reboot, or halt.

   .. versionadded:: 253

Exit status
###########

On success, 0 is returned, a non-zero failure code otherwise.

Notes
#####

These commands are implemented in a way that preserves basic compatibility with the original SysV commands. :man-pages:`systemctl(1)` verbs :code:`poweroff`, :code:`reboot`, :code:`halt` provide the same functionality with some additional features.

Note that on many SysV systems :code:`halt` used to be synonymous to :code:`poweroff`, i.e. both commands would equally result in powering the machine off. systemd is more accurate here, and :code:`halt` results in halting the machine only (leaving power on), and :code:`poweroff` is required to actually power it off.
