========================
sd_bus_message_rewind(3)
========================

Name
####

sd_bus_message_rewind — Return to beginning of message or current container

Synopsis
########

:code:`#include <systemd/sd-bus.h>` .. code-block::

   int sd_bus_message_rewind(sd_bus_message *m,
	int complete);

Description
###########

:code:`sd_bus_message_rewind()` moves the "read pointer" in the message :code:`m` to either the beginning of the message (if :code:`complete` is true) or to the beginning of the currently open container. If no container is open, :code:`complete` has no effect.

Return Value
############

On success, this function returns 0 or a positive integer. The value is zero if the current container or whole message in case no container is open is empty, and positive otherwise. On failure, it returns a negative errno-style error code.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   The :code:`m` parameter is :code:`NULL`.

.. systemd:option:: -EPERM

   The message :code:`m` has not been sealed.
