Name
####

sd_bus_message_new_method_call, sd_bus_message_new_method_return — Create a method call message

Synopsis
########

Description
###########

The :code:`sd_bus_message_new_method_call()` function creates a new bus message object that encapsulates a D-Bus method call, and returns it in the :code:`m` output parameter. The call will be made on the destination :code:`destination`, path :code:`path`, on the interface :code:`interface`, member :code:`member`.

Briefly, the *destination* is a dot-separated name that identifies a service connected to the bus. The is a dot-separated name that identifies a service connected to the bus. The *path* is a slash-separated identifier of an object within the destination that resembles a file system path. The meaning of this path is defined by the destination. The *interface* is a dot-separated name that resembles a Java interface name that identifies a group of methods and signals supported by the object identified by path. Methods and signals are collectively called is a dot-separated name that resembles a Java interface name that identifies a group of methods and signals supported by the object identified by path. Methods and signals are collectively called *members* and are identified by a simple name composed of ASCII letters, numbers, and underscores. See the `D-Bus Tutorial <https://dbus.freedesktop.org/doc/dbus-tutorial.html#concepts>`_ for an in-depth explanation.

The :code:`destination` parameter may be :code:`NULL`. The :code:`interface` parameter may be :code:`NULL`, if the destination has only a single member with the given name and there is no ambiguity if the interface name is omitted.

Note that this is a low level interface. See :ref:`sd_bus_call_method(3)` for a more convenient way of calling D-Bus methods.

The :code:`sd_bus_message_new_method_return()` function creates a new bus message object that is a reply to the method call :code:`call` and returns it in the :code:`m` output parameter. The :code:`call` parameter must be a method call message. The sender of :code:`call` is used as the destination.

Return Value
############

On success, these functions return a non-negative integer. On failure, they return a negative errno-style error code.

.. inclusion-marker-do-not-remove errors|

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -EINVAL

   The output parameter :code:`m` is :code:`NULL`.

   The :code:`destination` parameter is non-null and is not a valid D-Bus service name ("org.somewhere.Something"), the :code:`path` parameter is not a valid D-Bus path ("/an/object/path"), the :code:`interface` parameter is non-null and is not a valid D-Bus interface name ("an.interface.name"), or the :code:`member` parameter is not a valid D-Bus member ("Name").

   The :code:`call` parameter is not a method call object.

.. systemd:option:: -ENOTCONN

   The bus parameter :code:`bus` is :code:`NULL` or the bus is not connected.

.. systemd:option:: -ENOMEM

   Memory allocation failed.

.. systemd:option:: -EPERM

   The :code:`call` parameter is not sealed.

.. systemd:option:: -EOPNOTSUPP

   The :code:`call` message does not have a cookie.
