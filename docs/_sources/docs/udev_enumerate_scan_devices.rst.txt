Return Value
############

On success, :code:`udev_enumerate_scan_devices()`, :code:`udev_enumerate_scan_subsystems()` and :code:`udev_enumerate_add_syspath()` return an integer greater than, or equal to, :code:`0`.

On success, :code:`udev_enumerate_get_list_entry()` returns a pointer to the first entry in the list of found devices. If the list is empty, or on failure, :code:`NULL` is returned.

:code:`udev_enumerate_get_udev()` always returns a pointer to the udev context that this enumerated object is associated with.
