==================================
systemd-factory-reset-generator(8)
==================================

Name
####

systemd-factory-reset-generator — Pull

Synopsis
########

:code:`/usr/lib/systemd/system-generators/systemd-factory-reset-generator`

Description
###########

:code:`systemd-factory-reset-generator` is a generator that pulls :code:`factory-reset-now.target` into the initial boot transaction when the factory reset operation has been requested, either via the :code:`systemd.factory_reset=` kernel command line option or via the :code:`FactoryResetRequest` EFI variable.

:code:`systemd-factory-reset-generator` implements :ref:`systemd.generator(7)`.

See Also
########

:ref:`systemd(1)`, :ref:`systemd-factory-reset(8)`, `Factory Reset <https://systemd.io/FACTORY_RESET>`_
