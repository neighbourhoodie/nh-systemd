========================
systemd-socket-proxyd(8)
========================

Name
####

systemd-socket-proxyd — Bidirectionally proxy local sockets to another (possibly remote) socket

Synopsis
########

:code:`systemd-socket-proxyd [<OPTIONS>...] HOST:PORT`

:code:`systemd-socket-proxyd [<OPTIONS>...] UNIX-DOMAIN-SOCKET-PATH`

Description
###########

:code:`systemd-socket-proxyd` is a generic socket-activated network socket forwarder proxy daemon for IPv4, IPv6 and UNIX stream sockets. It may be used to bi-directionally forward traffic from a local listening socket to a local or remote destination socket.

One use of this tool is to provide socket activation support for services that do not natively support socket activation. On behalf of the service to activate, the proxy inherits the socket from systemd, accepts each client connection, opens a connection to a configured server for each client, and then bidirectionally forwards data between the two.

This utility's behavior is similar to :die-net:`socat(1)`. The main differences for :code:`systemd-socket-proxyd` are support for socket activation with "Accept=no" and an event-driven design that scales better with the number of connections.

Note that :code:`systemd-socket-proxyd` will not forward socket side channel information, i.e. will not forward :code:`SCM_RIGHTS`, :code:`SCM_CREDENTIALS`, :code:`SCM_SECURITY`, :code:`SO_PEERCRED`, :code:`SO_PEERPIDFD`, :code:`SO_PEERSEC`, :code:`SO_PEERGROUPS` and similar.

Options
#######

The following options are understood:

.. include:: standard-options.rst
    :start-after: .. inclusion-marker-do-not-remove help|
    :end-before: .. inclusion-end-marker-do-not-remove help|

.. include:: standard-options.rst
    :start-after: .. inclusion-marker-do-not-remove version|
    :end-before: .. inclusion-end-marker-do-not-remove version|

.. systemd:option:: --connections-max=, -c

   Sets the maximum number of simultaneous connections, defaults to 256. If the limit of concurrent connections is reached further connections will be refused.

   .. versionadded:: 233

.. systemd:option:: --exit-idle-time=

   Sets the time before exiting when there are no connections, defaults to :code:`infinity`. Takes a unit-less value in seconds, or a time span value such as "5min 20s".

   .. versionadded:: 246

Exit status
###########

On success, 0 is returned, a non-zero failure code otherwise.

Examples
########

Simple Example
##############

Use two services with a dependency and no namespace isolation.

proxy-to-nginx.socket
---------------------

.. code-block:: sh

   [Socket]
   ListenStream=80
   [Install]
   WantedBy=sockets.target

proxy-to-nginx.service
----------------------

.. code-block:: sh

   [Unit]
   Requires=nginx.service
   After=nginx.service
   Requires=proxy-to-nginx.socket
   After=proxy-to-nginx.socket
   [Service]
   Type=notify
   ExecStart=/usr/lib/systemd/systemd-socket-proxyd /run/nginx/socket
   PrivateTmp=yes
   PrivateNetwork=yes

nginx.conf
----------

.. code-block:: sh

   […]
   server {
       listen       unix:/run/nginx/socket;
       […]

Enabling the proxy
------------------

.. code-block:: sh

   # systemctl enable --now proxy-to-nginx.socket
   $ curl http://localhost:80/

If :code:`nginx.service` has :code:`StopWhenUnneeded=` set, then passing :code:`--exit-idle-time=` to :code:`systemd-socket-proxyd` allows both services to stop during idle periods.

Namespace Example
#################

Similar as above, but runs the socket proxy and the main service in the same private namespace, assuming that :code:`nginx.service` has :code:`PrivateTmp=` and :code:`PrivateNetwork=` set, too.

proxy-to-nginx.socket
---------------------

.. code-block:: sh

   [Socket]
   ListenStream=80
   [Install]
   WantedBy=sockets.target

proxy-to-nginx.service
----------------------

.. code-block:: sh

   [Unit]
   Requires=nginx.service
   After=nginx.service
   Requires=proxy-to-nginx.socket
   After=proxy-to-nginx.socket
   JoinsNamespaceOf=nginx.service
   [Service]
   Type=notify
   ExecStart=/usr/lib/systemd/systemd-socket-proxyd 127.0.0.1:8080
   PrivateTmp=yes
   PrivateNetwork=yes

nginx.conf
----------

.. code-block:: sh

   […]
   server {
       listen       8080;
       […]

Enabling the proxy
------------------

.. code-block:: sh

   # systemctl enable --now proxy-to-nginx.socket
   $ curl http://localhost:80/
