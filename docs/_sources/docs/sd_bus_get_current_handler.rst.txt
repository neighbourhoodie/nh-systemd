Description
###########

Whenever sd-bus is about to invoke a user-supplied callback function, it stores the current callback, D-Bus message, slot and userdata pointer and allows these to be queried via :code:`sd_bus_get_current_handler()`, :code:`sd_bus_get_current_message()`, :code:`sd_bus_get_current_slot()` and :code:`sd_bus_get_current_userdata()`, respectively. If :code:`bus` cannot be resolved or if execution does not reside in a user-supplied callback of :code:`bus`, these functions return :code:`NULL`.

Return Value
############

On success, these functions return the requested object. On failure, they return :code:`NULL`.
