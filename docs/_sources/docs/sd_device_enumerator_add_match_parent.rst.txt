Description
###########

The :code:`sd_device_enumerator_add_match_parent()` function adds a filter to the :code:`enumerator` so that only devices under the tree of the specified :code:`parent` device are enumerated. If this is called multiple times the previously set :code:`parent` device is cleared and only the last call takes an effect.

The :code:`sd_device_enumerator_add_match_property()` function adds a filter to the :code:`enumerator` so that only devices with the specified :code:`property` equals to the :code:`value` are enumerated. Both :code:`property` and :code:`value` can be a glob pattern. When this is called multiple times, devices that have at least one of the specified properties with matching values are enumerated. That is, filters are ORed.

The :code:`sd_device_enumerator_add_match_property_required()` function adds a filter to the :code:`enumerator` so that only devices with the specified :code:`property` equals to the :code:`value` are enumerated. This function is similar to :code:`sd_device_enumerator_add_match_property()`, but when this is called multiple times, devices that have *all* specified properties with matching values are enumerated. That is, filters are ANDed. specified properties with matching values are enumerated. That is, filters are ANDed.

The :code:`sd_device_enumerator_add_match_subsystem()` function adds a filter to the :code:`enumerator` so that all devices in the specified :code:`subsystem`, when :code:`match` is :code:`true`. When :code:`match` is :code:`false`, then all devices except those in the specified :code:`subsystem` are enumerated. When called multiple times, positive filters are ORed, and negative ones are ANDed.

The :code:`sd_device_enumerator_add_match_sysattr()` function adds a filter on the sysfs attribute :code:`sysattr` matching :code:`value`. :code:`value` can be a glob pattern. If :code:`value` is :code:`NULL`, devices that either have (if :code:`match` is :code:`true`) or do not have (if :code:`match` is :code:`false`) the specified :code:`sysattr` are included, regardless of its value. That is, :code:`NULL` is mostly equivalent to "*". When this function is called multiple times, only devices that match all specified :code:`sysattr` filters are enumerated. That is, these filters are ANDed.

The :code:`sd_device_enumerator_add_match_sysname()` function adds a filter so that only devices whose sysname equals to :code:`sysname` are enumerated. :code:`sysname` can be a glob pattern. When called multiple times, filters are ORed.

The :code:`sd_device_enumerator_add_nomatch_sysname()` function adds a filter so that devices whose sysname equals to :code:`sysname` are excluded from the enumeration. This is useful for excluding specific devices from the enumeration process. When called multiple times, features are ANDed.

The :code:`sd_device_enumerator_add_match_tag()` function adds a filter so that only devices tagged with :code:`tag` are enumerated. When called multiple times, filters are ORed.

The :code:`sd_device_enumerator_allow_uninitialized()` function allows devices that have not yet been initialized by udev to be included in the enumeration.

The :code:`sd_device_enumerator_add_all_parents()` function enumerates all parent devices of the matching devices. This is useful for cases where you want to include all parent devices in the enumeration, such as when you are interested in the entire device tree leading up to a specific device.

Return Value
############

All functions return :code:`0` or a positive integer on success, or a negative errno-style error code on failure.

Errors
######

Returned errors may indicate the following problems:

.. systemd:option:: -ENOMEM

   Memory allocation failed.

.. systemd:option:: -EINVAL

   One of the arguments is invalid.
