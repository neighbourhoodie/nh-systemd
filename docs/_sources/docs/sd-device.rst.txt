============
sd-device(3)
============

Name
####

sd-device — API for enumerating and introspecting local devices

Synopsis
########

:code:`#include <systemd/sd-device.h>`

:code:`pkg-config --cflags --libs libsystemd`

Description
###########

:code:`sd-device.h` is part of :man-pages:`libsystemd(3)` and provides an API to introspect and enumerate devices on the local system. It provides a programmatic interface to the database of devices and their properties mananaged by :ref:`systemd-udevd.service(8)`. This API is a replacement for :man-pages:`libudev(3)` and :code:`libudev.h`.

See
| :ref:`sd_device_get_syspath(3)`,
| :ref:`sd_device_ref(3)` for more information about the functions available.
